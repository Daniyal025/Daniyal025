Building an end-to-end platform that transforms a manually maintained economic Excel model into an automated analysis system.

- Mapped workbook logic and data lineage into structured system requirements.
- Designed the data model and automated ingestion pipeline.
- Built scheduled data collection and an inflation calculation engine.
- Added an **agentic AI layer** for grounded economic analysis and reporting.

**Stack:** Python · FastAPI · PostgreSQL · Web Scraping · AI Agents · Docker

### 🩻 Multimodal AI Clinical Decision Support

Developed a multimodal AI platform for radiology inference and clinical question answering.

- Built two FastAPI microservices for inference and multimodal RAG.
- Trained a **ResNet50 multi-label chest X-ray classifier**.
- Integrated **MedGemma-4B-IT** for multimodal reasoning.
- Implemented hybrid retrieval using **pgvector + full-text search + RRF + reranking**.
- Added SSE streaming, uploads, session memory, and LLM routing.

**Stack:** Python · PyTorch · FastAPI · MedGemma · ResNet50 · Supabase · pgvector · Groq
